# Pips Archive Android Implementation Plan

> Execute inline using superpowers:executing-plans. User waived further approval gates.

**Goal:** Deliver an installable Capacitor Android APK with normal timing and no hint disadvantages.
**Architecture:** Reuse the game and validated storage. Add a separate Vite client entry for the same routes, and Capacitor Android packaging. Historical assistance remains import-compatible while live hints are free.
**Tech Stack:** React, TanStack Router, Vite, Capacitor, Android Gradle.
**Spec:** docs/superpowers/specs/2026-10-14-android-design.md

## Global Constraints
- No hint time charges or performance exclusions, including old/imported results.
- Normal active-play timer remains.
- Bundled puzzles playable offline; saved progress survives pause and relaunch.
- APK must be signed/installable; keep keys and generated assets outside Git.

## Review Focus
- Old paid-hint imports keep their raw time and qualify for scoring.
- New hints can upgrade and resume without receipts or charges.
- Deep routes launch and reload without a web server.
- Android Back dismisses dialogs before navigating; pausing saves progress and stops active timing.
- Backups/results can leave the app through native sharing.
